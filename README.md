# davinci-resolve-clip-randomizer

DaVinci Resolve Lua script to randomly shuffle clips on a select timeline with video-audio-link preservation

## To use:
1. Download `.lua` file
2. Open `.lua` file and change `TARGET_NAME` to name of desired timeline
3. Open DaVinci Resolve -> Workspace -> Console
4. Drag `.lua` file into Console
5. Finished
